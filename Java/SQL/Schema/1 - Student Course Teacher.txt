### 3. **Teachers Table**

| Column      | Type         | Description               |
| ----------- | ------------ | ------------------------- |
| teacher\_id | INT (PK)     | Unique teacher identifier |
| name        | VARCHAR(255) | Teacher’s full name       |
| department  | VARCHAR(255) | Department name           |

**SQL:**

```sql
CREATE TABLE teachers (
    teacher_id INT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    department VARCHAR(255) NOT NULL
);
```

---

### 4. **Enrollments Table**

(*Junction table linking students and courses, many-to-many*)

| Column      | Type                      | Description                         |
| ----------- | ------------------------- | ----------------------------------- |
| student\_id | INT                       | FK to `students(student_id)`        |
| course\_id  | INT                       | FK to `courses(course_id)`          |
| PRIMARY KEY | (student\_id, course\_id) | Composite key to prevent duplicates |

**SQL:**

```sql
CREATE TABLE enrollments (
    student_id INT,
    course_id INT,
    PRIMARY KEY (student_id, course_id),
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
```

---

### 5. **Faculties\_Courses Table**

(*Junction table linking teachers and courses, many-to-many*)

| Column      | Type                      | Description                  |
| ----------- | ------------------------- | ---------------------------- |
| course\_id  | INT                       | FK to `courses(course_id)`   |
| teacher\_id | INT                       | FK to `teachers(teacher_id)` |
| PRIMARY KEY | (course\_id, teacher\_id) | Composite key                |

**SQL:**

```sql
CREATE TABLE faculties_courses (
    course_id INT,
    teacher_id INT,
    PRIMARY KEY (course_id, teacher_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id),
    FOREIGN KEY (teacher_id) REFERENCES teachers(teacher_id)
);
```
