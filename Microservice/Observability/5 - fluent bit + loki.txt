Below is a **real-world, end-to-end example** of how **Fluent Bit, Loki, Prometheus, and Grafana** work together in a **Spring Boot application running on Kubernetes**, with **deep focus on Fluent Bit** (what it does, how it’s configured, and why it’s used).

---

# 🌍 Real-World Scenario

### Context

You run a **Spring Boot microservices application** on Kubernetes:

* `order-service`
* `payment-service`
* `inventory-service`

Your goals:

* 📊 Monitor application health & performance (metrics)
* 📜 Collect and search logs centrally
* 🔗 Correlate metrics ↔ logs during incidents
* ⚡ Keep costs and operational complexity low

# 🟢 Spring Boot Application Setup

## 1️⃣ Logging (Logs to stdout)

Spring Boot logs to **stdout**, which is Kubernetes best practice.

Example log:

```text
2025-01-10 10:15:03 ERROR Payment failed for orderId=123
```

Kubernetes stores this as container logs:

```
/var/log/containers/payment-service-abc.log
```

👉 Fluent Bit reads these files.

---

## 2️⃣ Metrics (Micrometer + Actuator)

Spring Boot exposes metrics:

```
/actuator/prometheus
```

Example metrics:

* HTTP request count
* Latency
* JVM memory
* Thread count

Prometheus scrapes these.

---

# 🔵 Prometheus (Metrics Layer)

Prometheus:

* Discovers Spring Boot pods using Kubernetes service discovery
* Scrapes `/actuator/prometheus`
* Stores time-series metrics

Example alert:

> 🚨 `payment-service 5xx error rate > 2%`

Prometheus tells you **something is wrong**, but not **why**.

# 🟡 Fluent Bit (Logging Pipeline – Core Focus)

## What Is Fluent Bit?

**Fluent Bit** is a:

* Lightweight log processor & forwarder
* Runs as a **DaemonSet** (one per node)
* Collects logs from containers
* Enriches logs with metadata
* Sends logs to Loki

💡 Fluent Bit is preferred over Logstash because:

* Much lower CPU & memory
* Faster startup
* Kubernetes-native

---

## 📦 Fluent Bit Architecture

Fluent Bit uses a **pipeline model**:

```
[ INPUT ] → [ FILTER ] → [ OUTPUT ]
```

---

## 🧱 1. INPUT – Reading Container Logs

Fluent Bit reads logs from:

```
/var/log/containers/*.log
```

Example input config:

```ini
[INPUT]
  Name              tail
  Path              /var/log/containers/*.log
  Parser            docker
  Tag               kube.*
```

What this does:

* Tails container logs
* Parses JSON logs
* Tags logs for routing

---

## 🧠 2. FILTER – Enriching Logs (Very Important)

### Kubernetes Metadata Filter

Fluent Bit adds:

* Pod name
* Namespace
* Container name
* Labels (app, version, env)

Example filter:

```ini
[FILTER]
  Name                kubernetes
  Match               kube.*
  Merge_Log           On
  Keep_Log            Off
```

Now your log looks like:

```json
{
  "log": "Payment failed for orderId=123",
  "namespace": "prod",
  "pod": "payment-service-abc",
  "container": "payment-service",
  "labels": {
    "app": "payment-service",
    "version": "v1"
  }
}
```

💡 These labels are critical for Loki querying.

---

## 🚀 3. OUTPUT – Sending Logs to Loki

Fluent Bit sends logs to Loki over HTTP.

```ini
[OUTPUT]
  Name       loki
  Match      kube.*
  Url        http://loki:3100/loki/api/v1/push
  Labels     job=fluentbit,app=$kubernetes['labels']['app'],namespace=$kubernetes['namespace_name']
```

This converts Kubernetes metadata → **Loki labels**.

---

## 🟣 Loki (Log Storage Layer)

Loki:

* Indexes only labels (`app`, `namespace`, `pod`)
* Stores raw logs in chunks
* Uses filesystem or object storage

Example log stream in Loki:

```logql
{app="payment-service", namespace="prod"}
```

No full-text indexing → much cheaper.

---

## 📊 Grafana (Single Pane of Glass)

Grafana connects to:

* Prometheus (metrics)
* Loki (logs)

Grafana auto-runs:


# 🔥 Advanced Fluent Bit Use Cases

## 1️⃣ Log Filtering (Reduce Noise)

Drop INFO logs in prod:

```ini
[FILTER]
  Name   grep
  Match  kube.*
  Exclude log INFO
```

---

## 2️⃣ Multi-Destination Logs

Send:

* Errors → Loki
* Audit logs → S3
* Security logs → SIEM

Fluent Bit supports **multiple outputs**.

---

## 3️⃣ Structured Logs (JSON)

Spring Boot logs JSON:

```json
{"level":"ERROR","msg":"Payment failed","orderId":123}
```

Fluent Bit parses and sends structured fields to Loki.

---

# ⚖️ Why Fluent Bit (Not Promtail)?

| Fluent Bit          | Promtail     |
| ------------------- | ------------ |
| Multi-output        | Loki-only    |
| Ultra-lightweight   | Heavier      |
| Advanced filtering  | Simpler      |
| Enterprise-friendly | Loki-focused |

👉 Many real systems use **Fluent Bit → Loki**.
